- **Simulations** in Java: [Monte Carlo](https://github.com/tkozelek/DIS1_Monte_carlo), [event-driven](https://github.com/tkozelek/DIS2_Event_driven_simulation) and [agent-based](https://github.com/tkozelek/DIS3_Agent_Simulation), the last two modelling a furniture workshop.
